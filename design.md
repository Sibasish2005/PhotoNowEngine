# Design Skill: Hand-Drawn Portfolio Style

## Typography
- **Display/Hero** (name, huge headings): hand-lettered marker font, thick uneven strokes, all caps, wobbly baseline — e.g. `Permanent Marker`, `Caveat` (bold), or custom SVG hand font
- **Nav + Body**: hand-drawn monospace, thin strokes, all caps — e.g. `Space Mono` / `JetBrains Mono` run through a "sketch" filter, or `Kalam`
- **Scale contrast**: hero name ~8-10x body size; big jump, no mid-size headings
- **Case**: ALL CAPS throughout, no lowercase

## Color Theme
- Background: `#F2F2F0` (off-white / light gray)
- Text/lines: `#0A0A0A` (near-black)
- Illustration fill: solid black shapes (hat, hair, shirt) + white/bg negative space
- Accent block: inverted — black bg, white text (sidebar tab "W." / "Nominee")
- Strictly monochrome — zero color accents

## Layout
- Two-column split: illustration ~40% left, text content ~60% right
- Top nav: bracketed links `[ABOUT] [WORK] [LINKS]`, left-aligned, thin border-bottom
- Vertical tab strip fixed to right edge, rotated text, black bg
- Illustration boxed in a thin hand-drawn rectangle border
- Generous whitespace, no cards/shadows — flat, paper-like

## Motifs
- Hand-drawn borders (slightly imperfect rectangles) instead of clean CSS borders
- Doodle callouts (e.g. arrow + "HEY.") as annotations
- Line-art illustration style, minimal shading, bold black fills for hair/clothing
